# BabyFileCab

**BabyFileCab is a secure digital filing cabinet and workflow application built for tax and accounting professionals.**

It gives tax preparers, Enrolled Agents, CPAs, bookkeepers, and accounting firms one organized workspace for managing clients, tax documents, workflow, deadlines, time, and common tax-office tasks.

BabyFileCab is designed to keep client information organized without relying on a BabyFileCab-operated cloud document storage service.

---

## Features

### Client Document Management

Organize client documents using a structured filing system:

**Client → Tax Year → Section → Documents**

You can:

- Create and edit clients
- Assign client return types such as 1040, 1065, 1120-S, and 1120
- Create tax years and document sections
- Upload PDFs, Word documents, Excel files, CSV files, images, and other client documents
- Rename and delete documents
- Select multiple documents
- Maintain permanent client folders
- Add client notes
- Search for clients and documents
- Preview documents directly inside BabyFileCab

Documents can also be marked **Entered / Done** so you can easily see which documents have already been entered into the tax return.

---

## Firm Calendar

The Firm Calendar helps organize tax preparation workflow and client deadlines.

Calendar years include:

- 2025
- 2026
- 2027

You can:

- Assign clients to specific dates
- Assign clients to preparers
- Reassign clients to another date
- Reassign work to another preparer
- Search for a client and jump directly to their calendar date
- View the entire firm or filter by preparer
- Open client documents directly from the calendar

### Workflow Statuses

Scheduled clients can be assigned statuses such as:

- Drafting
- Waiting on Reports
- 8879 Sent
- Waiting for Signature
- Signed
- Ready to E-file
- Completed

The selected status is shown directly on the calendar.

Completed clients are highlighted so completed work can be identified quickly.

## Time Sheet

BabyFileCab includes a built-in time sheet for tracking work performed for clients.

You can:

- Select the date worked
- Select a client
- Enter hours worked
- Enter what you worked on
- Choose common work descriptions from a dropdown
- Type your own work description
- Edit existing time entries
- Delete incorrect entries
- View entries for a specific date
- View total hours worked

This makes it easier to track staff time and client work without maintaining a separate spreadsheet.

## Federal Tax Calculator

The calculator can estimate tax using information such as:

- Filing status
- Wages
- Self-employment income
- Interest
- Short-term capital gains
- Long-term capital gains
- Qualifying children

## Security

BabyFileCab was designed with sensitive tax and accounting documents in mind.

Security features include:

- AES-256-GCM encryption
- Company-specific encrypted vaults
- Argon2id password protection
- Encrypted backups
- Automatic locking after inactivity
- Configurable 15, 30, or 45 minute auto-lock
- Password changes
- Login protection
- Protected audit history
- Company-specific user access

Client documents remain stored locally on the user's computer rather than requiring them to be uploaded to BabyFileCab-operated cloud storage.

---

## Local-First Design

BabyFileCab is designed primarily as a **local-first desktop application**.

This means your client files stay on your own computer and inside your own BabyFileCab workspace.

Separate computers do not currently synchronize automatically.

## Report a Bug

If you discover a problem with BabyFileCab, please use the **Issues** section of this GitHub repository.

When reporting a bug, include:

- BabyFileCab version
- Operating system
- What you were doing
- What happened
- What you expected to happen
- Steps to reproduce the issue
- Screenshots when helpful

### Please protect client information

Never upload confidential client information to a public GitHub issue.

Do not post:

- Social Security numbers
- EINs
- Tax returns
- W-2s
- 1099s
- Bank statements
- Client addresses
- Passwords
- Encryption keys
- Confidential financial information

Use fictional or redacted information when reporting bugs.

## About BabyFileCab

BabyFileCab is built to bring the everyday tools of a tax and accounting office into one organized desktop workspace.

Instead of managing client documents, calendars, notes, time sheets, engagement letters, invoices, and other tools separately, BabyFileCab brings them together in one application.
