# Baby-File-Cab
BabyFileCab is a local Document Management System (DMS) built for solo practitioners, tax preparers, accountants, and small accounting firms. It was created by an Enrolled Agent to make day-to-day accounting and tax office work simpler, faster, and more organized.

Features:

Local client document management

Encrypted company and client data

Multiple users with Admin and Staff access

Client, tax year, section, and document organization

PDF preview, search, and rotation

PNG image preview

Client Notes and audit trail

Global document and client search

Document descriptions and properties

Client Communications directory

IRS Form 2848 generator

Engagement Letter generator

Invoice generator

2025/2026 Federal Tax Calculator

Client backup and restore tools

Multiple appearance themes

Windows installer — no Python installation required

Security:

BabyFileCab uses AES-256-GCM encryption and Argon2id password protection. Company vaults are kept separate, and BabyFileCab can automatically lock after inactivity.

Platform:

BabyFileCab is currently available for Windows. The application stores its data locally on the user's computer.

Author:

BabyFileCab was created and coded by an Enrolled Agent with accounting and tax preparation experience.
